# Plattenwart – Downloads

Hier liegen die Installationsdateien von **Plattenwart**, einer Desktop-App für Videografen und Fotografen
mit vielen externen Festplatten: Was liegt auf welcher Platte, wo sind die Backups, wo ist welche Platte gerade.

Die jeweils aktuelle Version findest du unter **Releases**.

- **Mac mit Apple-Chip:** Datei mit `arm64` im Namen
- **Mac mit Intel-Chip:** Datei ohne `arm64`

## Erster Start auf dem Mac

Plattenwart ist noch nicht bei Apple registriert. Deshalb beim ersten Mal:
im Ordner „Programme" mit der rechten Maustaste auf Plattenwart klicken, **Öffnen** wählen und noch einmal **Öffnen**.

## Datenschutz

Plattenwart liest nur Datei- und Ordnernamen, Größen und Änderungsdaten. Dateiinhalte werden nie hochgeladen.
